# Rehabilitation coverage audit — 135 linked pages

Date: 2026-09-06
Sector: `rehabilitation-functioning`

## Audit principle

Coverage is no longer expanded by page count alone. Before any new page is created, the live database is searched across the **entire site**, not only the rehabilitation sector.

The preferred order is:

1. If a strong page already exists in another sector, upgrade it if needed and cross-link it.
2. If a rehabilitation page exists but is incomplete, rebuild/upgrade it in place and preserve the canonical URL.
3. Create a new page only for a genuinely independent pathway, condition, methodology, or service gap.

This policy has already prevented duplicate rehabilitation pages for cerebral palsy, SMA, spina bifida, DMD, pressure injury, and several other topics.

## Important quality decisions made during the expansion

- **No generic dose rule:** condition-specific intensity recommendations are not generalized to all rehabilitation. For example, stroke-specific intensive therapy recommendations remain clearly scoped to stroke.
- **No automatic instrument republication:** proprietary or copyrighted scales are described and linked, not copied merely because they are clinically common.
- **Arabic translation is not treated as validation:** cross-cultural validity, structural validity, reliability, responsiveness and rights are handled separately.
- **No false endorsement:** using AAPM&R, WHO, NICE, COSMIN, COMET, AHA, ATS, ASIA, PVA, etc. as evidence sources does not imply institutional endorsement of Rawafid.
- **No stale directories:** Jordan/MENA service pages favor official pathways and verification methods over static facility lists that would quickly become outdated.
- **No duplicate disease pages:** strong pages in other sectors are upgraded and cross-linked where that produces a cleaner information architecture.

The measurement section now explains selection and psychometric logic. The next high-value work may be a **process guide for Arabic translation/cross-cultural adaptation projects** only if it can be kept distinct from the newly published instrument-selection guide and can use official rights/permission pathways.

### Priority D — Jordan/MENA official-source expansion

Continue only when official/local evidence is sufficient. Candidate directions:

- rights and reasonable accommodation in rehabilitation pathways;
- official workforce/service-data methodology;
- rehabilitation quality and accreditation context;
- regional continuity between health, education, social protection and employment.

Avoid legal or service-availability claims that cannot be tied to current official texts.

## Decision

The rehabilitation sector has moved from a sparse collection dominated by study analyses into a multi-layer reference architecture. The next phase should be **selective gap closure and maintenance**, not indiscriminate page growth.

Every future addition should either:

1. close an independent, verified search/clinical/service gap;
2. upgrade an inherited weak page to the current contract; or
3. make an existing high-quality page discoverable in rehabilitation through a justified cross-link.
