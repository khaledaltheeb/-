# Fragile X / FMR1 — Tier 2 Expansion Plan

Date: 2026-08-30
Sector: special-needs-inclusion
Root category: fragile-x-syndrome
Quality contract: V6, evidence-led rewrite, no gate bypass

## Purpose

The original 35-page cornerstone plan is now complete in production. Tier 2 closes operational and care-delivery gaps that are not adequately answered by the cornerstone pages and that merit distinct search intent rather than expansion of already-long pages.

## Anti-cannibalization rule

A Tier 2 page is created only if it owns a distinct user decision or workflow. If the question is already fully answered by an existing page, improve/cross-link the existing page instead of creating another URL.

## Priority Tier 2 pages

1. `fragile-x-emergency-hospital-care` — ED/hospital access, health passport, diagnostic overshadowing, sensory and communication adjustments, medication reconciliation, seizures, pain, discharge.
2. `fragile-x-anesthesia-procedures` — anesthesia, procedural sedation, perioperative preparation, airway/sleep apnea, seizures, psychotropics, postoperative behavior and pain; explicit evidence limitations because FXS-specific anesthesia evidence is sparse.
3. `fragile-x-pain-recognition-health-communication` — pain recognition in limited speech, AAC, behavior change, pain scales, health passport, avoiding diagnostic overshadowing.
4. `fragile-x-toileting-continence` — constipation vs continence skill, toilet training, sensory barriers, nocturnal enuresis, adult continence, school and supported living.
5. `fragile-x-aging-full-mutation` — aging with full-mutation FXS distinct from FXTAS; cognition, mobility, health, daily living, caregiver aging and surveillance gaps.
6. `fragile-x-cardiovascular-connective-tissue` — MVP/aortic root history, current surveillance evidence, joint/connective-tissue phenotype, when cardiology is warranted; avoid outdated antibiotic-prophylaxis assumptions.
7. `fragile-x-behavioral-crisis-deescalation` — acute escalation, medical causes, communication, sensory load, crisis plan, emergency thresholds; distinct from chronic autism/ADHD/anxiety management.
8. `fragile-x-health-passport-toolkit` — printable/interactive health information architecture only if implemented as a real tested tool; otherwise fold into emergency page.
9. `fragile-x-mena-diagnosis-access` — Arabic/MENA diagnostic access, referral architecture and verified regional resources. Requires country-by-country current verification and must not invent services.
10. `fragile-x-telehealth-remote-assessment` — when remote genetics/developmental/SLP/mental-health follow-up can help and where it fails; create only if enough FXS/IDD evidence supports distinct value.
11. `fragile-x-newborn-prenatal-screening-ethics` — screening vs diagnostic testing, carrier findings, consent, newborn-screening research, ethical implications; distinct from prenatal diagnosis page.
12. `fragile-x-registry-natural-history-data` — FORWARD/FORWARD-MARCH, registries, natural-history datasets, outcome measures, how families/researchers interpret registry evidence.

## Execution order

Emergency/hospital care -> anesthesia/procedures -> pain/communication -> toileting/continence -> aging/full mutation -> cardiovascular/connective tissue -> crisis/de-escalation -> MENA access -> screening ethics -> registry/natural history.

## Evidence requirements

- FXS-specific sources first: GeneReviews, AAP health supervision, FXCRC/NFXF, FXS cohorts.
- When FXS-specific evidence is sparse, explicitly label extrapolation and use high-quality IDD/disability clinical evidence.
- For rapidly changing clinical guidance, verify sources during authoring.
- No claim that general disability guidance is FXS-specific.
- Every indexed Tier 2 page must pass content contract V6 and strategic-scientific requirements before publication.
