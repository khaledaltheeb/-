# Addiction professional education continuity contract

Target repository: `khaledaltheeb/-`.

## Scope
This contract governs the future professional-education layer inside the existing `addiction-recovery` sector. It must extend the sector without duplicating the Addiction Atlas, treatment reference pages, family guidance, special-population pages, or research-magazine evidence summaries.

## Section identity
- Arabic name: `التعليم والكفاءات المهنية في رعاية اضطرابات استخدام المواد`
- Category slug: `addiction-professional-education`
- Planned public route: `/addiction/education/`
- Canonical taxonomy route: `/sections/addiction-professional-education`
- Parent sector: `addiction-recovery`
- Current lifecycle: `scaffold-ready`
- Current activation state: `hold-until-content-ready`

## Planned child journeys
1. `addiction-education-core-competencies` — core competencies and learning pathway.
2. `addiction-education-clinical-skills` — screening, assessment, brief intervention, motivational interviewing, risk recognition and referral.
3. `addiction-education-professional-roles` — profession-specific competencies and interprofessional practice.
4. `addiction-education-special-contexts` — pregnancy/postpartum, adolescents, older adults, co-occurring conditions, pain, violence/coercion and other special contexts.
5. `addiction-education-ethics-communication` — ethics, consent, privacy, stigma-free language, documentation and professional boundaries.
6. `addiction-education-evidence-implementation` — evidence appraisal, implementation, quality review and continuing professional development.

## Source model
AMERSA resources are an institutional framework source, not a section-name or ownership label. The section must remain an original Arabic evidence-based learning system. Expected source layers include:
- AMERSA Core Competencies.
- AMERSA education resources and relevant toolkits.
- Grayken Center / Boston Medical Center professional training resources.
- Current high-authority clinical guidelines and systematic evidence.
- Regional or country-specific sources where legal, regulatory, referral or availability claims are made.

AMERSA, Grayken, SAj or another institution must not be presented as having reviewed, endorsed, supervised or accredited Rawafid unless explicit written evidence supports that claim.

## Reuse and canonical policy
- Existing strong pages should be cross-listed rather than duplicated.
- Existing canonical URLs must be preserved when a pregnancy, older-adult, adolescent, peer-recovery or other page is reused in the professional-learning journey.
- A new page is justified only when it performs a distinct professional-learning function not already served by an existing page.
- The research magazine remains a living-evidence layer, not a substitute for competency or guideline pages.
- The Addiction Atlas remains a substance/evidence product, not a professional curriculum.

## Initial release floor
The parent category and all child categories remain inactive until the release wave contains at minimum:
1. A complete editorial landing page explaining audience, scope, limitations and navigation.
2. A substantive Arabic core-competencies reference page.
3. A professional page covering screening and structured assessment.
4. A dedicated SBIRT page.
5. A dedicated motivational-interviewing page.
6. Reviewed references and truthful provenance for every released page.
7. Internal-link review to existing treatment, harm-reduction, withdrawal, recovery and special-population pages.
8. Duplicate/canonical review proving that no existing content was cloned merely to fill the new section.

## Safety and clinical boundaries
- Educational content must not diagnose an individual or replace a licensed clinician.
- No self-managed dangerous-withdrawal schedules, non-medical dosing instructions, mixing recipes, intoxication optimization or unsupported potency claims.
- Screening tools must not be described as stand-alone diagnoses.
- Professional-role pages must separate education from jurisdiction-specific scope of practice.
- US-specific regulation, DEA rules, reimbursement rules or program structures must be explicitly labeled and never generalized to Jordan or the wider Arab region.
- Medication availability, legality and referral pathways require local verification before regional claims are published.

## Evidence semantics
- A competency framework defines what professionals should know or be able to do; it is not automatically a current clinical-practice guideline.
- Research articles, systematic reviews, toolkits, position statements and clinical guidelines must remain visibly distinguishable evidence types.
- Older framework material may structure the curriculum while current guidelines update clinical recommendations.
- Emerging evidence must not be presented as established practice merely because it is newer.

## Activation rule
Do not set the parent or children `is_active = true` merely because the taxonomy exists. Activation happens only in a release migration after the initial release floor has been met and verified.

## Current scaffold state
The database scaffold intentionally contains zero assigned content. This is the expected state until the content-building phase begins.
