# خارطة الوصول إلى أكثر من 5000 صفحة في منصة روافد

## المبدأ

الهدف ليس بلوغ رقم 5000 بصفحات رقيقة، بل بناء شبكة عربية مؤسسية واسعة، لكل صفحة فيها نية مستقلة، قيمة عملية، مصادر، ومسار Canonical واضح. العدد نتيجة للتغطية المنهجية، لا بديلًا عنها.

## نموذج التوسع

تتوسع المنصة عبر وحدات مترابطة:

1. **المراجع المركزية**: الحالات والاضطرابات والاحتياجات الكبرى.
2. **الأدلة العملية**: الأسرة، المدرسة، المختص، والعمل والحياة اليومية.
3. **المقارنات**: نيات «الفرق بين» التي تستحق صفحة مستقلة.
4. **القدرات والوصول**: الإعاقات والاحتياجات الوظيفية والتسهيلات.
5. **الأبحاث المفسرة**: مراجعات ودراسات حديثة بلغة عربية دقيقة.
6. **الأدوات**: مقاييس وحاسبات وتجارب تفاعلية موثقة وآمنة.
7. **التصنيف والمصطلحات**: صفحات داعمة عندما تملك وظيفة بحثية وتنقلية حقيقية.
8. **ملفات المختصين والمراكز**: صفحات ديناميكية مفهرسة فقط عند اكتمال الجودة والتحقق.

## توزيع تخطيطي

| المسار | نطاق الصفحات المستهدف |
|---|---:|
| الصحة النفسية وعلم النفس | 900–1200 |
| التوحد وADHD والتنوع العصبي | 650–850 |
| التربية الدامجة والتربية الخاصة | 650–850 |
| صعوبات التعلم واللغة والتواصل | 500–700 |
| الإعاقات والمتلازمات والقدرات | 550–750 |
| الطفل والأسرة والمدرسة | 600–800 |
| الإدمان والتعافي | 300–450 |
| البحث والقياس والأدوات | 350–500 |
| المقارنات والمصطلحات المنظمة | 400–600 |
| المختصون والمراكز والبرامج الموثقة | متغير بحسب التحقق |

هذه الأرقام حدود تخطيطية وليست حصص نشر آلية.

## بوابة إنشاء أي صفحة

لا تنشأ صفحة إلا عندما تجتاز القرارات التالية:

- هل توجد صفحة حالية أو قديمة تملك النية نفسها؟
- هل الأفضل تطوير Canonical قائم أو إنشاء صفحة جديدة؟
- هل المحتوى يستحق URL مستقلًا أم قسمًا داخل صفحة أم؟
- هل توجد مصادر أولية أو إرشادية أو مراجعات قوية كافية؟
- هل يمكن ربط الصفحة داخليًا بشبكة ذات معنى؟
- هل يمكن صيانة الصفحة ومراجعتها دوريًا؟

## الحد الأدنى التحريري

عقد V6 يفرض على الصفحات التحريرية الموسعة حدًا مستهدفًا لا يقل عن 2500 كلمة عربية مفيدة، لكن العدد وحده لا يكفي. يجب أن تتضمن الصفحة، بحسب نوعها:

- تعريفًا وحدودًا دقيقة للمصطلح.
- رحلة مستخدم منظمة من الفهم إلى القرار العملي.
- تمييزًا بين الادعاء المثبت والاستنتاج والتحفظ.
- أسئلة بحث فعلية، لا FAQ مصطنعة.
- روابط داخلية تمنع العزلة والتنافس الدلالي.
- مراجع موثقة وخريطة ادعاءات.
- بيانات المؤلف والمراجع وتاريخ المراجعة.

الأدوات والصفحات التفاعلية تخضع لعقد صحة وأداء وإتاحة بدل حد الكلمات.

## مراحل التنفيذ

### المرحلة 1: تثبيت الأساس

- دمج PR #182 ثم PR #183 ثم طبقة الطلب التحريري.
- إعادة جرد المصدر القديم وطابور V6 من الالتزام نفسه.
- تفسير فرق 50 مسارًا والوصول إلى صفر فرق غير مفسر.
- تثبيت Taxonomy وCanonical registry والRedirect registry.

### المرحلة 2: استعادة المحتوى القديم

- تحليل كل صفحة قديمة وإصدارات مصدرها.
- دمج المكرر والمحافظة على القيمة الفريدة.
- إنشاء Redirect دائم لكل مسار تم دمجه أو نقله.
- عدم نقل CSS أو القالب أو التنبيهات المتكررة من المستودع القديم.

### المرحلة 3: توسعة المراكز الأساسية

- الصحة النفسية.
- التوحد وADHD.
- التربية الدامجة.
- اللغة والتواصل وصعوبات التعلم.
- الطفل والأسرة والمدرسة.

### المرحلة 4: التوسع طويل الذيل

تنشأ الصفحات الفرعية من فجوات مثبتة في البحث وسلوك المستخدم، مع تجميع المرادفات ومنع صفحات المدن أو الأعمار أو الأعراض المتطابقة بنيويًا.

### المرحلة 5: التشغيل المستمر

- مراجعة علمية دورية.
- تحديثات Last reviewed وLast modified الصادقة.
- مراقبة الصفحات الضعيفة أو اليتيمة أو المتنافسة.
- دمج الصفحات عند تغير النية أو تداخلها.
- قياس جودة الجلسة والوصول إلى المعلومة، لا الزيارات وحدها.

## مؤشرات النجاح

- صفر صفحات بلا Canonical واضح.
- صفر Redirect chains أو حلقات.
- صفر صفحات منشورة بلا مراجع عند الحاجة.
- صفر ادعاءات اكتمال مع فرق جرد غير مفسر.
- تحسن التغطية الموضوعية والربط الداخلي وقابلية الوصول.
- نمو عدد الصفحات بعد اجتياز البوابات، لا قبلها.
