# Rawafid Institutional Design System V5

- الاتجاه: RTL أولًا، مع قابلية تعدد اللغات.
- الأساس: White / Off-white.
- الهوية: Teal / Turquoise.
- النص المؤسسي: Dark Teal.
- Accent محدود: Gold.
- القطاعات: Coral / Lilac / Green / Blue / Gold.
- الواجهة العامة Editorial وليست Admin Template.
- مساحات بيضاء كبيرة، Typography قوي، Cards عند الحاجة، Micro-interactions هادئة، وصور بشرية عالية الجودة.
- لوحة الإدارة والمختص منفصلتان بصريًا ووظيفيًا عن الموقع العام.
- رمز الهوية هو «الرافد»: نقطة مصدر ومساران متدفقان، وليس حرفًا عربيًا أو لاتينيًا منفردًا.
- الصفحة الرئيسية متمحورة حول نية الزائر: معلومة، دعم مهني، مساندة قريب، أو أداة عملية.
- شريط الثقة يصف ما يفهمه الزائر: المراجعة والمصادر والخصوصية وحدود الإرشاد، لا أسماء تقنيات التنفيذ.
- الواجهة الإدارية متمحورة حول المهمة: طابور تحقق موحد، إجراءات سريعة، مؤشرات اكتمال، وقوالب إنشاء صفحات.
- الحركة قصيرة وهادئة، وتلغى عبر `prefers-reduced-motion`.
