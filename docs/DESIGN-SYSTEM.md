# Rawafid Institutional Design System V5.2

- الاتجاه: RTL أولًا، مع قابلية تعدد اللغات.
- الأساس: White / Off-white مع أسطح هادئة وطبقات شفافة محدودة.
- الهوية: Teal / Turquoise، مع رمز «الرافد» الحالي في `RawafidBrand` كنقطة مصدر ومسارات متدفقة.
- النص المؤسسي: Dark Teal.
- Accent محدود: Gold.
- القطاعات: Coral / Lilac / Green / Blue / Gold كإشارات دلالية، لا كهويات بديلة.
- الواجهة العامة Editorial وليست Admin Template.
- مساحات بيضاء كبيرة، Typography عربي قوي، Cards عند الحاجة، وMicro-interactions هادئة.
- لوحة الإدارة والمختص منفصلتان بصريًا ووظيفيًا عن الموقع العام مع مشاركة Tokens والإتاحة الأساسية.
- الصفحة الرئيسية متمحورة حول نية الزائر: معلومة موثوقة، دعم مهني، مساندة قريب، أداة أو دليل، ثم الاستكشاف الموضوعي.
- شريط الثقة يصف ما يفهمه الزائر: المراجعة والمصادر والخصوصية وحدود الإرشاد، لا أسماء تقنيات التنفيذ.
- المحتوى الحديث في الصفحة الرئيسية لا يُعرض إلا إذا كان منشورًا، قابلًا للفهرسة، وبلغ تاريخ نشره الفعلي.
- الشريط المؤسسي العلوي يوفّر وصولًا مباشرًا إلى «عن روافد»، منهجية المراجعة، ومسار المختصين والجهات دون إزاحة التنقل الأساسي.
- الحركة قصيرة وهادئة، وتلغى عبر `prefers-reduced-motion`.
- لا يُعاد إنشاء شعار أو Header أو Footer خاص بكل قطاع؛ تستخدم المكونات المركزية الحالية.
- كل إضافة بصرية يجب أن تبقى قابلة للاختبار عبر عقود الثيم وTypeScript وLint وBuild وSmoke وLighthouse.
