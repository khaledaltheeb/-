# Rawafid Institutional Design System V3

- الاتجاه: RTL أولًا، مع قابلية تعدد اللغات.
- الأساس: White / Off-white.
- الهوية: Teal / Turquoise.
- النص المؤسسي: Dark Teal.
- Accent محدود: Gold.
- القطاعات: Coral / Lilac / Green / Blue / Gold.
- الواجهة العامة Editorial وليست Admin Template.
- مساحات بيضاء كبيرة، Typography قوي، Cards عند الحاجة، Micro-interactions هادئة، وصور بشرية عالية الجودة.
- لوحة الإدارة والمختص منفصلتان بصريًا ووظيفيًا عن الموقع العام.
