# Magazine migration — 2026-08-08

## Scope
- Source: `khaledaltheeb/healthrenewal.org`, directory `magazine/`.
- Destination: the current Rawafid Next.js application and its existing Supabase `public.content` publication model.
- Source inventory: 79 research-analysis HTML pages, plus the section index and RSS feed.

## Migration contract
1. Preserve each legacy article URL exactly as `/magazine/<legacy-file>.html`.
2. Preserve the complete scientific reading, including research question, design/sample, results, limitations, practical interpretation, FAQ, original-source citation and documentation sidebar.
3. Do not carry the legacy visual theme, analytics snippets or static shell into the new application.
4. Store migrated pages as `content_type=research` and retain source provenance in `schema_json` (`legacy_source_html`, canonical, blob SHA, source size, source repository and verification date).
5. Retain at least one original scholarly/source URL in `references_json` for every research record.
6. Enforce the platform publication gate: published records require an SEO title, 150–160 character description, primary keyword, visible author and authoritative reference.
7. Keep the global content sitemap as the source for article discovery; preserve `/magazine/feed.xml` as a dynamic RSS endpoint.

## Verification completed before application merge
- 79/79 legacy research files fetched successfully from the source repository.
- 79/79 records migrated to Supabase with `status=published`.
- 79 distinct magazine canonical URLs; no canonical duplicates.
- 79/79 have at least one preserved source reference.
- Every record has at least 13 structured body blocks; observed range: 13–29.
- SEO title length range: 33–47 characters.
- SEO description length: 158 characters for all migrated records.

## Rendering upgrade
The new route uses the shared Rawafid header/footer, responsive layout, semantic content renderer, `ScholarlyArticle`, breadcrumb and FAQ structured data, source-reference sections, evidence-kind labels, related readings and the legacy `.html` route shape.
