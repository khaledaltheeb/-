# Rawafid Life OS — Android

هذه ليست نسخة WebView من الموقع. التطبيق طبقة حياة يومية فوق `healthrenewal.org`؛ الموقع يبقى محرك المعرفة، بينما تعمل أدوات الهاتف محليًا قدر الإمكان.

## الدفعة المنفذة في v0.2

- واجهة Native متعددة الأقسام: الرئيسية، اهتم بي، الأدوات، الأمان، المعرفة.
- Light/Dark design system عالي التباين وRTL.
- تذكير اختياري «ارمش الآن» لراحة العين.
- تذكير الحركة والتنفس بعد الجلوس.
- تذكير الماء بتردد يختاره المستخدم.
- رسائل تحفيزية: التردد والحد اليومي بيد المستخدم.
- ساعات صمت تمنع التذكيرات المزعجة.
- مواعيد علاج محلية عبر AlarmManager، مع إعادة الجدولة بعد إعادة تشغيل الهاتف.
- «فضفض ثم اتركها»: النص لا يُكتب إلى SharedPreferences أو خادم، ويزول من الذاكرة عند ترك الشاشة.
- عداد ماء يومي محلي.
- بطاقة طوارئ محلية قابلة للمشاركة كنص.
- موقع روافد داخل WebView مقيد بنطاق `healthrenewal.org`، والروابط الخارجية تخرج إلى المتصفح.
- لا تعتمد التذكيرات أو فضفض أو بطاقة الطوارئ على Supabase أو Cloudflare.

## الخصوصية

التفضيلات والمواعيد والبطاقة تحفظ في SharedPreferences على الجهاز في هذه المرحلة. `allowBackup=false` لمنع نسخ هذه البيانات ضمن النسخ الاحتياطي التقليدي للتطبيق. «فضفض» لا تُحفظ أصلًا.
