## Systemic issue fixed

`lib/seo.ts` previously built a semantic profile and emitted a subset through Next.js `Metadata.keywords`. Google Search does not use the meta-keywords tag for indexing/ranking, and Rawafid query maps belong in private editorial/SEO planning. The central helper was changed to stop public emission while retaining caller input compatibility.

The repository contracts were aligned with the intended architecture: the 50 topical + 50 intent signals remain validated internally, but their existence is no longer coupled to public meta-keywords emission.
