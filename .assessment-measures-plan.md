# Global assessment measures library — implementation contract

## Public identity
- Public Arabic name: **المقاييس وأدوات التقييم المستخدمة عالميًا**.
- Canonical hub: `/assessment-measures/`.
- This library is independent from `/assessment-lab/` and must never change the Assessment Lab 70-route contract.
- The library documents established external measures, their evidence, intended use, administration, scoring boundaries, Arabic-version status, and reuse rights.

## Rights-first publication rule
A measure may be marked `full-reuse-verified` only when an authoritative rights source explicitly supports redistribution/reproduction of the exact original instrument (for example Public Domain or an open licence covering the instrument). `Free`, `$0`, `freely available`, a downloadable PDF, or inclusion in RMD is not sufficient by itself.

The rights record must distinguish:
1. original instrument rights;
2. exact translation rights;
3. permission/conditions for reproduction;
4. verification source URL;
5. verification date.

If any point is unclear, publish only a reference/usage guide and link to the canonical provider. Never reproduce protected item wording, item order, scoring keys, proprietary translations, forms, or cut-offs beyond what can be responsibly summarized.

## Arabic-version rule
Public-domain status of an English/original instrument does not automatically make an existing Arabic translation public domain. Do not label an Arabic version as validated unless an identifiable validation study supports that exact version/population. A Rawafid translation may be described only as an informational translation unless it has completed an appropriate linguistic and psychometric validation program.

## Scientific completeness per measure
Every published measure page must include, where applicable:
- Arabic and English names and acronym;
- construct/purpose;
- intended populations and common settings;
- assessment type and administration mode;
- approximate administration time and equipment/training needs;
- scoring architecture and interpretation boundary;
- explicit statement that a measure is not automatically a stand-alone diagnosis;
- known limitations or context dependence;
- Arabic-version status;
- original-instrument rights status and translation-rights status separately;
- RMD source and an authoritative rights/source record;
- last rights verification date;
- related measures and category navigation.

## Evidence rule
RMD is an evidence-discovery and synthesis source, not the copyright owner for most instruments. Prefer the original publication/owner, RMD, CDISC QRS permission metadata, Mapi Research Trust/ePROVIDE, official professional bodies, or official measure sites for rights and source verification. Never convert an RMD `Cost: Free` field into a redistribution claim without a separate rights basis.

## Safety and clinical boundaries
- Do not represent library inclusion as universal endorsement, accreditation, or approval.
- Do not present screening, symptom, function, outcome, or quality-of-life scores as stand-alone diagnoses.
- Preserve population/context-specific interpretation. Do not generalize cut-offs, MCID/MDC, norms, sensitivity, or specificity across populations.
- Where administration requires clinician skill, training, safety precautions, equipment, or medical judgment, state it visibly.
- Do not create unofficial diagnostic cut-offs or severity bands.

## Current verified release
The first public release contains only measures whose original-instrument reuse status has a documented Public Domain/reproduction basis in the catalog. Measures with ambiguous, conditional, commercial, translation, or institution-specific terms remain in the rights-review queue and are not reproduced in full.

## Information architecture
- `/assessment-measures/` — searchable/browsable library hub.
- `/assessment-measures/category/[slug]/` — functional/category collections.
- `/assessment-measures/[slug]/` — individual evidence/rights/use page.
- Category membership can be many-to-many; do not duplicate the underlying measure record.

## SEO/accessibility
- Arabic RTL first-class, semantic headings, keyboard navigation, visible focus, descriptive link text, readable tables/cards, responsive layout.
- Self-canonical metadata, index/follow on reviewed public routes, BreadcrumbList and CollectionPage/WebPage structured data, static sitemap inclusion, useful internal links.
- Avoid doorway pages, duplicated descriptions, keyword stuffing, and claims such as “best”, “approved”, or “globally accredited” unless a source specifically supports them.

## Maintenance
Every rights record carries `rightsVerifiedOn`. Re-check rights when an owner/provider changes terms, when a new translation is added, or before embedding a full form that was previously linked only. If sources conflict, use the more restrictive current interpretation until resolved.
