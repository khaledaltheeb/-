# منصة روافد — Rawafid Institutional Platform V3

المستودع الجديد لمنصة روافد. هذا المشروع يُبنى من الصفر ولا يرث الثيم أو المكونات البرمجية من المستودع القديم.

## المرحلة الحالية

Foundation فقط: الهوية، البنية، قاعدة البيانات، الصلاحيات، CMS، المختصون، المراكز، الحسابات، البحث، SEO، PWA، المراسلة والمواعيد. لا يتم ترحيل المحتوى القديم قبل اكتمال واختبار هذه الأنظمة.

## التقنية

- Next.js Active LTS + React + TypeScript
- Supabase Postgres/Auth/Realtime/Storage
- GitHub Actions CI
- RTL Arabic-first design system

## متغيرات البيئة

انسخ `.env.example` إلى `.env.local` وأضف Project URL وSupabase Publishable Key فقط. المفاتيح السرية لا توضع في الواجهة أو المستودع.
