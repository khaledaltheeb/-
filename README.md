# منصة روافد — Rawafid V3

المستودع الجديد لمنصة روافد المؤسسية. هذه المرحلة مخصصة لبناء الثيم والبنية والربط والاختبارات فقط، **دون نقل أي محتوى من المستودع القديم**.

## الحالة الحالية

- Next.js + React + TypeScript
- RTL عربي افتراضي
- Design System مؤسسي زاهٍ
- Supabase للبيانات والحسابات وRLS
- مخطط أولي: مستخدمون، قطاعات، محتوى وإصدارات، مختصون، مراكز، محادثات، مواعيد، إشعارات، Redirects وAudit Logs
- SEO مضبوط مؤقتًا على `noindex` حتى اكتمال الاختبارات وقبل ربط الدومين

## مبدأ الترحيل

المستودع القديم سيكون **مصدر محتوى فقط** بعد اكتمال المنصة الجديدة. لن يتم نقل الثيم أو CSS أو Layout أو Components القديمة.
