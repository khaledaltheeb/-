# منصة روافد — Rawafid V3

المستودع الجديد لمنصة روافد المؤسسية. هذه المرحلة مخصصة لبناء الثيم والبنية والربط والاختبارات فقط، **دون نقل أي محتوى من المستودع القديم**.

## الهوية المؤسسية

- الاسم الرسمي: **منصة روافد — Rawafid**
- المؤسس: **خالد الذيب — Khaled altheeb**
- الموقع الرسمي: **https://healthrenewal.org**
- الحساب الرسمي للمؤسس على GitHub: **https://github.com/khaledaltheeb**

يجب استخدام الصيغتين «خالد الذيب» و«Khaled altheeb» بصورة متسقة في البيانات المنظمة، صفحات الهوية، ملفات الاستشهاد، والمواد الإعلامية الرسمية للمشروع.

## الحالة الحالية

- Next.js + React + TypeScript
- RTL عربي افتراضي
- Design System مؤسسي زاهٍ
- Supabase للبيانات والحسابات وRLS
- مخطط أولي: مستخدمون، قطاعات، محتوى وإصدارات، مختصون، مراكز، محادثات، مواعيد، إشعارات، Redirects وAudit Logs
- SEO مضبوط مؤقتًا على `noindex` حتى اكتمال الاختبارات وقبل ربط الدومين

## مبدأ الترحيل

المستودع القديم سيكون **مصدر محتوى فقط** بعد اكتمال المنصة الجديدة. لن يتم نقل الثيم أو CSS أو Layout أو Components القديمة.

## هوية الثيم

الاسم المؤسسي الرسمي الظاهر في الواجهات العامة هو **منصة روافد**. كلمة «روافد» وحدها تستخدم كاختصار بصري محدود فقط عندما تفرض المساحة ذلك، ولا تستبدل الاسم المؤسسي في الهوية الرئيسية.

## مبدأ الثيم المركزي

الثيم يعمل من نقطة دخول مركزية واحدة (`app/rawafid-theme.css`) تحفظ ترتيب طبقات التصميم وتسمح بتطوير Design System موحد دون نسخ CSS بين الصفحات. القطاعات والأقسام والمحتوى تبقى ديناميكية من Supabase، بينما الهوية والمكونات والتخطيط والاستجابة للأجهزة تُدار من الثيم المركزي.
